# Yerel Excel şablonları

Public depo gerçek işlem satırları içeren Excel şablonlarını barındırmaz.

Şirkete özel şablon kullanmak isterseniz aşağıdaki dosyaları Git tarafından
izlenmeyen `templates/local/report_editing/` klasörüne koyun:

- `sales_template.xls`
- `collections_template.xls`

Dosyalar bulunmazsa uygulama veri içermeyen Excel 97–2003 çıktılarını koddan
üretir.
